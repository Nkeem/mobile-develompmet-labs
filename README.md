# Лабораторные работы по мобильной разработке

Android-приложения на Kotlin. Среда разработки — Android Studio.

Каждая лабораторная выполняется в отдельной ветке от актуальной `main`.
После выполнения создаётся Pull Request с описанием решения; слияние в `main`
производится после проверки и исправления замечаний.

Сообщения коммитов: `type(scope): description`, без кириллицы.
