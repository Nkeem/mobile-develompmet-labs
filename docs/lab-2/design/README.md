# Макеты трекера полива

Проектные макеты: список растений, карточка и форма. Варианты: `light` - светлая тема, `dark` - тёмная, `en` - английский язык. Общий вид - `overview.png`.

Compose-прототипы находятся в `PlantDesignPreviews.kt` и открываются в режиме Design/Split Android Studio. Данные фиксированные, действия кнопок ещё не реализованы.
